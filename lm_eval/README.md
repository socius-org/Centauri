# lm_eval

General-purpose LLM benchmark results using [lm-evaluation-harness](https://github.com/EleutherAI/lm-evaluation-harness).

## Contents

- `cogsoc/` — CogSoc benchmark results (JSON per model)
- `metabench/` — MetaBench benchmark results (JSON per model)
- `hf_model_cards/` — Generated HuggingFace model card YAML files (one folder per model)
- `lm_eval_to_model_cards.py` — Converts lm_eval JSON results into HuggingFace model card format
