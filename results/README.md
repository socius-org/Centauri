# results

All evaluation results, analysis scripts, and generated figures.

## Subdirectories

- `Psych101/` — Psych-101 behavioral evaluation: per-task CSVs, scaling/quantization plots, heatmap tables, and martingale property tests
- `Psych201-RT/` — Psych-201 reaction-time probing: hidden-state extraction and tutorial notebooks
- `lm_eval/` — General LLM benchmarks (CogSoc, MetaBench) and HuggingFace model card generation
